Smart Incident Management System

A ServiceNow-based incident management platform developed to manage and track student support requests efficiently.

## Features

* Incident ticket creation
* Incident tracking system
* Custom tables and forms
* Dashboard analytics
* Workflow automation using Flow Designer
* Priority and status management

## Technologies Used

* ServiceNow
* Flow Designer
* Dashboard Analytics
* Workflow Automation

## Modules

* Ticket Management
* Incident Dashboard
* Records Tracking
* Workflow Configuration
